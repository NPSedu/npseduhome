Getting Started with PyCharm

Everything you need to install PyCharm, write and run your first Python program, and start climbing the challenge ladder — at your own pace, on your own device.

⏱ 20–30 minutes 🖥 Windows, macOS or Linux 🎓 No experience required
1
Step 1 of 4

Download PyCharm

  1. Go to jetbrains.com/pycharm/download
  2. Choose your operating system (Windows, macOS, or Linux)
  3. Click Download under Community — that's the free edition
  4. Wait for the installer to finish downloading
Note: Community edition is completely free and has everything we need for this course. Ignore the Professional edition.

2
Step 2 of 4

Run the installer

  1. Open the file you downloaded
  2. Click through the setup wizard
  3. The default options are fine — just click Next each time
  4. Click Install, then Finish once it completes
Tip: Installing can take a few minutes. A good moment to help a neighbour who's stuck on step 1.

3
Step 3 of 4

Create a new project

  1. Open PyCharm for the first time
  2. Click New Project
  3. Leave the location and interpreter as the default
  4. Click Create — this may take a moment the first time
Note: "Interpreter" just means which version of Python runs your code. The default is fine for now.

4
Step 4 of 4

Write and run your first program

  1. Right-click your project → New → Python File
  2. Type the line of code shown opposite
  3. Click the green ▶ Run arrow (or right-click → Run)
  4. Check the console at the bottom for your output
✓ Success looks like: the text "Hello, IB Computer Science!" appears in the console below your code.

Practice

The Challenge Ladder

Start at Level 1 and see how far you climb. Don't worry if you can't finish them all — each level introduces one new idea.

1

Hello

Output a greeting to the console.

Hello, world!
2

Hello, human

Ask the user for their name, then greet them by name.

What is your name? Nicole Hello, Nicole!
3

Calculator

Ask for two numbers and display their total.

First number: 12 Second number: 7 Total: 19
4

Decisions

Ask the user their age. Tell them whether they are under 18 or 18+.

How old are you? 15 You are under 18.
5

Repetition

Use a loop to output the numbers 1 through 10, one per line.

1 2 3 ... 10
6

Functions

Create a function larger_number(a, b) that returns whichever number is larger.

larger_number(4, 9) >>> 9
★ Boss Level

Number Guessing Game

For anyone who's already comfortable with Python. The computer should:

  1. Choose a random number between 1 and 100
  2. Ask the player to guess
  3. Tell them "Too high" or "Too low"
  4. Keep asking until they're correct
  5. Count how many guesses they needed
⭐ Extension: can you stop the user entering something that isn't a valid number?
Guess a number (1-100): 50 Too high! Guess a number (1-100): 25 Too low! Guess a number (1-100): 37 Too high! Guess a number (1-100): 31 Correct! You got it in 4 guesses.
