Stage 1 · About 8 minutes

What is SQL?

SQL (Structured Query Language) is used to communicate with a relational database management system (DBMS). Some database applications use visual interfaces, but SQL statements can operate behind the scenes.

DDL (Data Definition Language) defines or changes the structure of a database. DML (Data Manipulation Language) works with the records stored in tables. In this lesson, SELECT is grouped with DML, as in your course slides.

Quick check: DDL or DML?

第一关：认识 SQL

SQL（结构化查询语言）用于与关系数据库管理系统（DBMS）交互。有些数据库软件提供图形界面，但后台仍可使用 SQL 语句。

DDL（数据定义语言）用于创建或修改数据库的结构，例如表和字段。DML（数据操作语言）用于查询、添加、修改或删除表中的数据。本课程将 SELECT 归入 DML。

Stage 2 · About 15 minutes

DDL: Design the structure

CREATE TABLE creates a table; ALTER TABLE changes its structure; DROP TABLE removes the entire table. PRIMARY KEY identifies a record uniquely. A FOREIGN KEY references a key in another table.

Common types: INT for whole numbers, VARCHAR(n) for text up to n characters, DATE for dates, REAL for decimal numbers, and BOOLEAN for true/false. NOT NULL means a value must be supplied.

CREATE TABLE LibraryBook (
  BookID INT PRIMARY KEY,
  Title VARCHAR(100) NOT NULL,
  Published DATE
);
ALTER TABLE LibraryBook ADD ShelfCode VARCHAR(10);

第二关：使用 DDL 建立数据库

CREATE TABLE 创建表；ALTER TABLE 修改表的结构；DROP TABLE 删除整个表。PRIMARY KEY（主键）唯一标识每条记录；FOREIGN KEY（外键）引用另一张表的键。

常见数据类型：INT 整数，VARCHAR(n) 最多 n 个字符的文本，DATE 日期，REAL 小数，BOOLEAN 真/假。NOT NULL 表示必须填写值。

第三关：使用 DML 查询数据
SELECT 选择要显示的字段；FROM 指定表；WHERE 筛选记录；ORDER BY 排序。先预测查询结果，再点击 Run query 查看数据。
DISTINCT 去重；JOIN ... ON 根据匹配的字段连接两个表；GROUP BY 分组；HAVING 筛选分组；BETWEEN 包含边界的范围；LIKE 'S%' 匹配以 S 开头的文本；ASC 升序；DESC 降序；AND / OR / NOT 组合条件。
注意：WHERE 筛选单独的记录；HAVING 筛选分组后的结果。

Stage 4 · About 20 minutes
Write SQL yourself
These commands change records, not the table structure:
INSERT INTO LibraryBook (BookID, Title)
VALUES (7, 'Database Basics');

UPDATE LibraryBook
SET Title = 'SQL Basics'
WHERE BookID = 7;

DELETE FROM LibraryBook
WHERE BookID = 7;
Safety rule: Always check your WHERE clause when updating or deleting. Without it, you can change or delete every row.

What happens when indexed data changes?
An index can speed up finding records, but inserting, updating or deleting indexed values may also require updating the index. Many large changes can slow write operations and may require index maintenance or reorganisation. The exact impact depends on the DBMS and workload.
第四关：自己编写 SQL
INSERT INTO ... VALUES 添加新记录；UPDATE ... SET ... WHERE 修改现有记录；DELETE FROM ... WHERE 删除记录。修改或删除时要特别检查 WHERE 条件，否则可能影响整张表。
