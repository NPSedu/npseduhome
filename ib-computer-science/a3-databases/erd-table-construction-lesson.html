Quick reference

Entity
Something about which the database stores data.
Attribute
A property that describes an entity.
Relationship
A connection between entities, commonly expressed using a verb.
Modality
Minimum participation: zero (optional) or one (mandatory).
Cardinality
Maximum participation: one or many.
Junction table
Resolves an M:N relationship into two 1:M relationships.
Primary key
Uniquely identifies a record in a table.
Foreign key
References a primary key in another table.
Composite key
Two or more attributes used together as the primary key.
Concatenated key
A combined value constructed from multiple attribute values.
