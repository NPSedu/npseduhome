Quick reference

Conceptual
Entities, attributes and relationships.
Logical
Tables, keys, junction tables, types and constraints.
Physical
Implementation, indexes, partitions, storage and backups.
Primary key
Uniquely identifies a record.
Foreign key
Links to a primary key in another table.
Data type
Defines what kind of value a field can store.
